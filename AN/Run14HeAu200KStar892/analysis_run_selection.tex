This analysis was based on 133 subsets (runs) which were available for taxi build ana.{\color{red}{??}}. 
It is important to have consistent data in each subset for any measurement over the whole dataset to be accurate. 
This analysis was performed with charged tracks only therefore each run was investigated for charged track multiplicity and DC occupancy distribution.

Multiplicity was investigated by measuring 2 variables for each run - ratio of number of charged tracks $N_{\text{charged}}$ to the number of events $N_{\text{evt}}$ and ratio of positively $N_{\text{charged}}^+$ to negatively $N_{\text{charged}}^-$ charged tracks. 
Calculated values are shown on Fig. \ref{fig:run_mult_check}. 
Runs outside the 30\% window of deviation from the mean value were rejected (3 runs rejected in total).

The investigation of DC occupancy distributions was performed by comparing normalized DC heatmaps projection on board from each run to the MC simulated one (Sec. \ref{sec:systematics_acceptance}). 
Comparison was performed by taking a ratio of a real to the simulated board distributions. 
0-th order polynom fit was performed on obtained ratios. 
The constant fit parameter and $\chi^2/\text{NDF}$ of approximation were investigated for DC occupancy consistency.
These values for each run are shown on Fig. \ref{fig:run_dc_check}.
Runs were found to be consistent in constant parameter value deviation from the mean (less than 3\%) and there were no runs that exceeded $\chi^2/\text{NDF} > 3$ threshold, therefore no runs were removed by DC occupancy check.
